# 🏠 House Price Prediction using Machine Learning

## 📌 Project Overview

This project is a Machine Learning-based House Price Prediction system developed using Python. It uses a Linear Regression algorithm to predict house prices based on various features such as area, number of bedrooms, bathrooms, stories, parking availability, air conditioning, and furnishing status.

The project includes data preprocessing, model training, prediction, model evaluation, data visualization, and interactive house price prediction through user input.

## 🎯 Objectives

- Load and explore a housing dataset.
- Preprocess categorical data into numerical values.
- Separate features and target variables.
- Split the dataset into training and testing sets.
- Train a Linear Regression Machine Learning model.
- Predict house prices using test data.
- Evaluate model performance using MAE, MSE, and R² Score.
- Visualize actual vs predicted house prices.
- Predict the price of a new house using user-provided details.
